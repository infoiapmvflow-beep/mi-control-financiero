# MI CONTROL
App personal para registrar ingresos, comisiones, retenciones, gastos de negocio/personales, ahorro, facturación y saldo mensual.

## Uso
Abrir `index.html` en el navegador. Los datos se guardan localmente en el navegador. Usar **Exportar respaldo** periódicamente.

## Publicación
Puede publicarse en GitHub Pages, Netlify o Vercel como sitio estático.
